# 0.13.0 Alpha 2 — 전체 한국어 더빙과 더빙 대사 자막

이 비공식 AI 한국어 더빙은 무전 WAV 1,847개(발화 구간 1,943개)와 영상 56개를 대상으로 합니다. Gemini TTS로 제작하고 무전 필터·음량·길이를 보정한 최종 음성을 제공합니다. 설치할 때 Google 계정, API 키, TTS 호출은 필요하지 않습니다.

지원 게임은 기존 패치와 같은 Windows x64 **2608.3123.1.0** 패키지입니다. Xbox 실기용 패치가 아닙니다. 원본 게임은 별도로 필요합니다.

## 다운로드와 설치 순서

GitHub의 자동 생성 Source code ZIP 대신 다음 설치용 파일을 받으세요.

1. 기존 [0.11.0 베타 1](https://github.com/schultz1138/crimson-skies-korean-wide/releases/tag/v0.11.0-beta.1)을 설치합니다. 이미 0.12 언어팩을 사용한다면 **그 버전의 실행기로 원본 언어팩 상태를 복구**하여 0.11 기반으로 돌아온 뒤 진행하세요. 저장 프로필은 지울 필요가 없습니다.
2. 게임과 ‘플레이’ 창을 모두 종료합니다. 새 릴리즈의 `CrimsonSkies-Korean-Dub-0.13.0-alpha.2.zip` 전체를 풀고 `KoreanDubInstaller.exe`를 실행합니다. 게임 폴더 또는 `Content`를 선택한 뒤 **검사 → 더빙 설치**를 누릅니다. 설치·백업·임시 복원에 추가 여유 공간 약 14GB를 권장합니다.
3. `CrimsonSkies-Dub-Subtitles-0.13.0-alpha.2.zip`을 별도 폴더에 풀고 `PrepareSubtitleLauncher.exe`를 실행합니다. 같은 게임 폴더를 선택하고 **자막 선택기 열기**를 누릅니다. 처음에는 소유한 게임에서 자막용 데이터를 로컬로 준비합니다. 이 준비 도구는 게임 파일을 쓰지 않습니다.
4. 자막 선택기에서 **한국어 — 더빙 대사 자막**을 선택하고 **적용 후 실행**을 누릅니다. 기존 ‘플레이’ 창으로 연결됩니다. 자막과 음성 모두 게임 안에서 재생되며 별도 자막 오버레이는 사용하지 않습니다.

두 ZIP에 있는 도구·차분·JSON 파일을 함께 보관하세요. 자막 준비가 끝난 뒤에는 같은 폴더의 `MultilingualLauncher.exe`를 직접 실행해도 됩니다. 다른 PC나 새 게임 설치에는 준비 도구를 다시 사용하세요.

전체 더빙만 설치해도 한국어 음성은 나옵니다. 자막 ZIP은 **기존 번역 자막 / 최종 더빙 대사 자막**을 선택하는 추가 도구입니다. 두 자막 모드 모두 한국어 음성을 유지합니다. 이전 English/Spanish 예제 언어팩은 전체 더빙 기반과 호환되는 팩으로 제공하지 않습니다.

## 복구와 업그레이드

영어 원음을 되돌리려면 다음 순서로 진행합니다.

1. 게임과 ‘플레이’ 창을 종료합니다.
2. Alpha 2 자막 선택기에서 **원본 자막 복구**를 눌러 전체 더빙 기반의 기존 번역 자막으로 돌아갑니다.
3. `KoreanDubInstaller.exe`의 **복구**를 누릅니다. 이 더빙 설치 직전의 0.11 기반 파일과 실행기 언어 메뉴로 돌아갑니다.

자막을 먼저 복구하지 않으면 더빙 설치기의 해시 검사가 현재 파일을 거부합니다. 다른 모드나 알 수 없는 파일을 덮어쓰지 않기 위한 동작입니다. 각 도구의 백업은 `%LOCALAPPDATA%\CrimsonSkiesFullDubPublic\Backups` 및 `%LOCALAPPDATA%\CrimsonSkiesSubtitlePacks\Backups`에 보관됩니다. 백업을 지우면 해당 설치의 복구 기능을 사용할 수 없습니다.

이전 개인 시험판이나 로컬 Alpha 1/Alpha 2에서 올라오는 경우에는 **기존 도구로 먼저 기존 번역 자막 상태로 복구**하세요. 새 공개 실행기는 다른 백업의 소유권을 임의로 가져오지 않습니다. 새로운 공개 전체 더빙 팩은 0.11 기반에서의 새 설치를 지원하며, 중간 더빙 시험판을 차례로 설치할 필요는 없습니다.

프로필 백업·선택 삭제·ZIP 복원 기능은 자막 실행기에 유지됩니다. 음성·자막 설치는 저장 프로필을 수정하지 않습니다. 해상도·AA 설정도 수정하지 않으며, 음성 설치기는 한국어 리소스를 사용하는 실행기 언어 메뉴를 포함합니다.

일부 환경에 남는 영어 컷신 음성 ZIP 캐시도 설치·복구 방향에 맞춰 갱신합니다. 등록된 지원 게임의 캐시에 해당 ZIP이 있을 때만 처리하며, 갱신 전 캐시를 백업합니다. 체크포인트·캐시 목록·다른 캐시의 바이트는 보존합니다. 게임 복사본을 대상으로 시험하는 경우 등록 게임의 공용 캐시는 수정하지 않습니다.

## Alpha 2 캐시 수정

게임은 임시 저장소의 `data.zip`과 설치된 파일의 **크기만 비교**합니다. 같은 크기의 자막 묶음은 내용이 바뀌어도 이전 캐시를 계속 사용할 수 있습니다.

기존 번역 묶음은 15,113,239바이트, 이번 더빙 자막 묶음은 15,113,240바이트로 만들어 전환 시 게임이 자동으로 다시 복사하도록 했습니다. ZIP 중앙 디렉터리 앞 패딩과 디스크 디렉터리의 파일 크기만 조정합니다. 게임 파서가 EOCD를 파일 끝에서 정확히 22바이트 앞에서 읽으므로 ZIP 주석은 사용하지 않습니다. 앞으로 더빙 자막 데이터를 변경하는 릴리즈도 직전 판과 다른 지원 가능한 논리 크기를 선택해야 합니다.

## 검증 범위

- 공개 0.11 기반 → 전체 더빙의 차분 21개를 모두 디코딩하여 최종 전체 파일 해시를 확인했습니다.
- 별도 게임 복사본에서 전체 더빙 설치 → 복구 → 재설치와 알 수 없는 입력·손상된 차분 거부를 확인했습니다.
- 공개 자막 준비 도구를 기존 번역 상태와 더빙 대사 상태에서 각각 실행해 같은 로컬 자막 데이터가 생성되는지 확인했습니다. 자막 전환·복구·재적용과 손상된 로컬 자막 데이터 거부도 확인했습니다.
- 공개 소스로 재빌드한 Native·Data0000·Data0005 세 파일이 실제 사용 중인 Alpha 2와 정확히 일치했습니다.
- 음성 캐시의 합성 XTAF 시험에서 설치·원음 복구·원자적 되돌리기, 재실행, 손상된 ZIP·순환 할당·잘못된 형식 거부를 검사했습니다. 체크포인트와 다른 캐시 바이트도 대조했습니다. 실제 등록 게임의 캐시 형식·연결 확인은 읽기만 했습니다.
- 사용자가 수정된 영상 자막의 실제 표시를 확인했습니다. 전체 영상·엔딩까지의 장시간 플레이 검증이 끝났다는 뜻은 아닙니다. 영상 내 문장 분할 시점은 최종 음성의 발화 구간과 읽기 속도에 맞춘 배치이며 단어 단위 강제 정렬은 아닙니다.

배포 ZIP에는 원본 게임 DLL, SVOD 볼륨, 완성 Bink 영상, 원본 음성, 로컬 백업, API 키를 포함하지 않습니다. 설치 도구·차분·검증용 메타데이터와 라이선스 안내를 제공합니다.
