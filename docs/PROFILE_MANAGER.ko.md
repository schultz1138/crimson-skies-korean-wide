# 프로필 관리자 — 0.12.2 알파

**한국어** | [English](PROFILE_MANAGER.en.md) · [자막 언어팩](MULTILINGUAL.ko.md)

자체 실행기의 **프로필 관리 / Profiles**에서 로컬 프로필을 확인하고, 선택한
프로필 하나만 백업하거나 백업 후 삭제하고, 선택한 백업 ZIP을 복원할 수 있습니다.
행을 선택하거나 더블클릭하는 것만으로는 저장 데이터를 변경하지 않습니다.
이미 있는 프로필은 덮어쓰지 않습니다. **저장 크기 / Save size**는 데이터 용량이며,
캠페인 진행률을 해석한 값이 아닙니다.

이 기능은 Windows 패키지 x64 게임 **2608.3123.1.0**, 패키지 패밀리
`Xbox360BackwardCompatibil.PrimaryCrimsonSkiesHighR_ksqcvrsvwz2jp`와 검증된 로컬
WGS 인덱스 버전 14에 한정한 실험 기능입니다. 알 수 없는 메타데이터, 여러 계정이나
변경된 저장소 식별자, 오래된 선택 상태, 지원되지 않는 상태에서는 변경을 거부합니다.
모든 Xbox 클라우드 저장소를 지원하는 편집기가 아닙니다. 자막 언어 전환에는 기존
0.11 기반 패치가 필요하며, 이번 프로필 기능으로 게임 코드·글꼴·언어팩 카탈로그의
기존 페이로드를 바꾸지는 않습니다.

## 사용

1. 게임을 저장하고 **게임과 기존 Play 창을 모두 종료**합니다.
2. 새 `CrimsonSkies-Multilingual-0.12.2-alpha.1` 묶음의
   `MultilingualLauncher.exe`를 실행해 지원되는 게임 폴더를 선택하고
   **프로필 관리 / Profiles**를 누릅니다.
3. **새로 고침 / Refresh** 후 저장소·프로필 식별자를 확인하고 한 행을 선택합니다.
4. **선택 프로필 백업 / Back up selected**는 삭제 없이 해당 프로필 ZIP을 만들고
   검증합니다. 작업 기록에 백업 경로가 표시됩니다.
5. **백업 후 삭제 / Backup + delete**는 프로필 이름·저장 크기·저장 식별자를
   보여주며 진행 기록까지 삭제됨을 따로 확인합니다. 먼저 새 백업을 만들고 검증해야
   삭제할 수 있으며, 선택하지 않은 로컬 프로필과 공유 타이틀 데이터도 다시 검증합니다.
6. 없는 프로필을 복원하려면 행 선택 없이 **백업 ZIP 복원 / Restore ZIP**을 누르고
   이 관리자가 만든 ZIP을 선택합니다. 검사는 읽기만 수행합니다. 프로필 이름·원본
   식별자·대상 저장소·ZIP 크기·SHA-256을 확인한 뒤 별도 확인 창에서 **예**를
   선택해야 복원합니다. 기본 응답은 **아니요**입니다. 같은 프로필이 있거나 다른
   식별자·이름 충돌이 발견되면 중단하며 덮어쓰기를 제안하지 않습니다. 쓰기 직전에
   ZIP과 저장소를 다시 검사하고, 다른 프로필·공유 타이틀 데이터의 보존 여부를
   확인합니다. 작업 후 목록을 다시 읽습니다.

삭제는 우선 로컬 저장소에 반영됩니다. 클라우드 동기화 대기 상태를 표시하며,
다음 정상 게임/저장 공급자 실행 때 지원되는 삭제 표식을 처리하고 동기화합니다.
관리자 자체는 클라우드 공급자를 호출하지 않습니다. 인덱스가 지원되는 확정 상태가
아니면 일반 게임/공급자가 동기화를 마치게 한 뒤 종료하고 새로 고침하세요.
단, 이 도구의 중단 작업이 있다고 나오면 **복구를 먼저** 해야 합니다. 지원 여부를
확인하지 못한 상태에서 임의로 저장소를 고치지 않으며, 버튼 비활성 사유를 표시합니다.

일반 사용에는 **Microsoft GDK/SDK나 xgamesaveutil 설치가 필요 없습니다**.
SDK 도구·내보내기 파일·개인 계정 식별자·실제 저장 데이터·공급자 검증용 임시
컨테이너를 소스나 배포물에 포함하지 않습니다.

## 백업과 중단 작업 복구

선택한 프로필의 ZIP 백업은 WGS 밖의
`%LOCALAPPDATA%\CrimsonSkiesProfileManager\Backups`에 저장합니다. 해시와
계정·저장소·프로필 연결 정보, 선택한 원본 파일 및 CDATA를 사용하는 단일 컨테이너
`selected-profile.xml`이 들어 있습니다. 저장 데이터와 계정 정보가 있으므로
백업은 비공개로 보관하세요. 전체 저장소 교체용 내보내기가 아닙니다.

**백업 ZIP 복원 / Restore ZIP**은 이 관리자가 검증한 백업에서 현재 없는 프로필
하나를 복원합니다. 의도적으로 삭제한 뒤 보관한 백업도 사용할 수 있으며 전체
저장소를 교체하지 않습니다. 이번 버전은 백업에 기록된 원래 계정과 정확한 저장소
환경이 일치해야 합니다. 다른 계정이나 옮긴 WGS 저장소로 이전하는 기능이 아닙니다.
ZIP 파일 자체의 위치는 옮겨도 됩니다. 복원된 프로필에는 새로운 로컬 저장 식별자가
부여될 수 있으며, 결과 기록은 백업의 원본 프로필도 함께 식별합니다. 선택한 ZIP의
검증된 비공개 사본을 보관하고 경로를 기록합니다. 동기화 대기 상태라면 다음 정상
게임/저장 공급자 실행 때 동기화합니다.

**중단 작업 복구 / Recover**는 이 도구에서 중단된 작업만 처리하는 별도 기능이며,
완료된 백업을 가져오는 버튼이 아닙니다. 나중에 프로필이 필요할 수 있다면 검증된
ZIP을 보관하세요. 백업 ZIP 복원에는 SDK 가져오기나 전체 저장소 `/replace`를
사용하지 않습니다.

작업이 중단됐다면 게임과 Play 창을 닫고 관리자를 다시 열어 **Recover**를 명시적으로
누릅니다. 목록 확인이나 선택만으로 자동 복구·쓰기를 하지 않습니다. 복구 대기 중에는
백업·삭제·ZIP 복원이 비활성화되며 새 실행기의 **적용 후 실행 / Apply & open**과 CLI
`--open`도 중단 작업을 먼저 해결하도록 합니다. 복구가 필요한 동안 다른 실행기나
이전 실행기로 우회해 게임을 켜지 마세요. 복구 자료는
`%LOCALAPPDATA%\CrimsonSkiesProfileManager\Transactions`에 보관하며 활성 작업
표식·인덱스 사본·검증된 백업을 수동으로 지우면 안 됩니다.
작업 인증 키는 Windows DPAPI CurrentUser로 보호합니다. 중단 작업의 **Recover는
작업을 시작한 동일한 Windows 사용자·프로필**에서 실행해야 합니다. 복구 기록은
다른 사용자로 옮겨 쓰는 일반 복원 수단이 아니며 Windows 재설치도 같은 인증 상태를
보장하지 않습니다.

기존 언어팩의 복구 식별자 `CrimsonSkies-Multilingual-0.12.0-alpha.1`과 카탈로그
바이트·해시는 유지합니다. 새 배포 폴더·버전만 분리해 기존 자막 적용 기록과
호환되며 이전 묶음·바로가기·0.11 설치기의 원본 게임 복구 백업은 제거하지 않습니다.
**0.11 복구 / Restore 0.11**는 자막·게임 파일에 관한 기능이며, 의도적으로 삭제한
프로필을 복원하지 않습니다.

## 소스 빌드

[재현 빌드 안내](REPRODUCING.ko.md)의 고정 Python·의존성 환경을 사용합니다.

```powershell
.\.venv\Scripts\python.exe multilingual\build.py `
  --input-content D:\CrimsonSkies-original\Content `
  --dependencies .deps `
  --out D:\CrimsonSkies-profile-build-001
```

실행기·프로필 소스만 바꾼 경우에는 보관한 **비공개 전체 소스 빌드 결과**를
다시 사용할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe multilingual\build.py `
  --package-from D:\prior-private-full-build `
  --repo-root . --out D:\CrimsonSkies-profile-package-001
```

이 경로도 기존 기반·언어별 목표 파일을 검사하고 모든 차분을 다시 복원해 검증합니다.
새 번역을 만드는 경로가 아니며 공개 ZIP만으로 실행할 수 없습니다. Windows의
.NET Framework 컴파일러와 Compression/FileSystem·System.Security 참조로 C# 소스 11개를 빌드하며
SDK는 필요 없습니다. 지정된 `0.12.2-alpha.1.zip`만 공유하고 비공개 `work/`,
프로필 백업 또는 SDK 검증 자료는 포함하지 마세요.
