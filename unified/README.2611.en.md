# Build 2611 compatibility preview

Requires an owned Windows x64 **2611.323.502.0** game with the stock files from the Xbox update. Backups made by earlier builds belong to those builds.

Close the game and Play window, extract the entire ZIP, and open CrimsonSkiesSetup.exe. Select the game Content folder, run Check, select your voice and caption preset and widescreen option, then install. Use the same version's Restore button to return to the installation baseline.

Build from owned 2611 stock Content, an owned 2608 stock Native DLL and the extracted public Beta 2 bundle. Use the existing CPython toolchain with pefile, Capstone and Keystone. See the command in [the Korean guide](README.2611.ko.md).
