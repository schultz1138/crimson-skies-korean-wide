# 0.14.1 Beta 1 설치·복구 안내 — 게임 빌드 2611

**[다운로드](https://github.com/schultz1138/crimson-skies-korean-wide/releases/tag/v0.14.1-beta.1)** · [English](https://github.com/schultz1138/crimson-skies-korean-wide/blob/main/unified/README.2611.en.md)

Windows PC에 직접 설치한 **Crimson Skies: High Road to Revenge, x64 2611.323.502.0** 전용입니다. 게임은 별도로 필요하며 Xbox 콘솔·클라우드 플레이에는 적용할 수 없습니다. **2608.3123.1.0에는 [0.14.0 Beta 2](https://github.com/schultz1138/crimson-skies-korean-wide/releases/tag/v0.14.0-beta.2)**를 사용하세요.

## 업데이트 후 처음 적용한다면

Xbox 앱에서 버전을 확인하세요. 원본 게임의 정상 실행과 컨트롤러 연결을 확인한 뒤, 게임과 ‘플레이’ 버튼이 있는 런처를 모두 닫습니다. 전체 더빙에는 **추가 여유 공간 약 14GB**를 권장합니다. 게임 드라이브와 Windows 사용자 폴더 드라이브를 모두 확인하세요.

| 현재 상태 | 할 일 |
| --- | --- |
| 패치 없는 2611 원본 | 바로 설치 가능 |
| 2608에 이전 패치 적용 중, 아직 게임 업데이트 전 | 이전 설치기의 **설치 전 복구** 후 Xbox 앱에서 게임 업데이트 |
| 이미 2611로 업데이트했는데 파일 검사가 실패 | 2608 백업을 덮어쓰지 말고 Xbox 앱의 **검사 및 복구**로 2611 원본 준비 |
| 이번 0.14.1 Beta 1 설치 완료 | 같은 설치기에서 옵션 변경·복구 가능 |
| 다른 시험판이나 알 수 없는 변경이 남음 | 해당 설치기로 먼저 복구하거나 Xbox 앱에서 원본 복구 후 검사 |

**게임 업데이트 전후의 설치기와 백업을 섞지 마세요.** 2608 백업으로 2611을 복구할 수 없습니다. 새 게임 빌드가 나오면 지원 확인 전까지 적용을 보류하세요.

## 다운로드부터 첫 실행까지

1. [릴리스 Assets](https://github.com/schultz1138/crimson-skies-korean-wide/releases/tag/v0.14.1-beta.1)에서 **`CrimsonSkies-Unified-0.14.1-beta.1.zip`**을 받습니다. `Source code`는 개발용 소스입니다.
2. ZIP **전체를 새 폴더에 압축 해제**하고 `CrimsonSkiesSetup.exe`를 실행합니다. `manifest.json`, `patches`, `tools`를 함께 두세요. Python 설치, API 키, 음성 생성 작업은 필요 없습니다.
3. **폴더 선택 / Browse**에서 실제 게임 설치 폴더 또는 `Content`를 선택합니다. 예: `C:\XboxGames\Crimson Skies- High Road to Revenge\Content`. 위치는 Xbox 앱의 게임 관리에서 확인할 수 있습니다.
4. 아래 표에서 음성·자막 프리셋 하나와 와이드 옵션을 고릅니다.
5. **상태 검사 / Check → 선택 항목 설치 / Install selected** 순서로 진행합니다. 오류가 나오면 강행하지 마세요.
6. **‘선택한 구성요소 설치와 전체 검증을 마쳤습니다.’** 메시지를 기다립니다. 설치 중 게임이나 다른 설치기를 실행하지 마세요.
7. **플레이 창 열기 / Open game**를 누릅니다. 와이드 적용 시 런처의 **설정 → 그래픽 → 해상도**에서 **1920×1080 (1080p, 16:9)** 또는 **3840×2160 (4K, 16:9)** 등을 선택한 뒤 플레이합니다. 변경은 다음 실행에 적용됩니다. 4K와 MSAA는 GPU·메모리 부담이 큽니다.

## 어떤 옵션을 고르나요?

| 원하는 구성 | 음성·자막 프리셋 | 와이드스크린·고해상도 |
| --- | --- | --- |
| 영어 음성 + 한국어 무전 자막 | **영어 음성 + 한국어 자막** | 원하는 대로 |
| 한국어 음성만 듣기 | **한국어 더빙만 (추가 자막 끔)** | 원하는 대로 |
| 한국어 음성 + 대사에 맞춘 자막 | **한국어 더빙 + 맞춤 자막** | 원하는 대로 |
| 화면만 와이드로 | **원본 음성·자막** | **켬** |
| 모든 패치 옵션 끄기 | **원본 음성·자막** | **끔** |

‘더빙만’에서도 기본 영상 자막과 필요한 한글 메뉴·글꼴은 유지합니다. 와이드는 별도 선택입니다. 더빙은 미리 제작한 AI 한국어 음성 파일입니다.

## 옵션 변경과 복구

게임과 런처를 닫고 **같은 버전의 설치기**에서 새 옵션을 골라 **상태 검사 → 선택 항목 설치**합니다. 이번 설치 이전으로 돌아가려면 **설치 전 복구 / Restore pre-install**를 사용합니다. 모든 옵션을 끄는 것과 설치 전 백업 복구는 다른 작업입니다.

변경 파일과 설치기가 변경하는 설정·캐시는 확인하고 백업하며 사용자 저장 프로필을 덮어쓰지 않습니다. 백업 폴더를 보관하세요. 게임 업데이트 전에 복구하고, 이미 업데이트했다면 다른 빌드 백업 대신 Xbox 앱의 원본 복구를 사용하세요.

## Smart App Control (SAC)

**배포본은 미서명입니다. SAC가 설치기, 동봉 도구 또는 패치된 게임 DLL을 차단할 수 있습니다. 설치기 실행만으로 게임 실행까지 보장하지 않습니다. 이번 릴리스는 SAC 차단을 해결하는 업데이트가 아닙니다.**

SAC를 끄면 PC 전체의 앱 실행 보호가 줄어듭니다. 다시 켤 수 있는지는 PC·Windows 버전과 상태에 따라 다르며, 다시 켜면 패치 게임이 재차단될 수 있습니다. **‘설치할 때만 껐다가 켜면 된다’고 가정하지 마세요.** 설치기는 보안 설정을 자동 변경하지 않습니다. SAC를 유지해야 하는 환경에서는 적용을 보류하세요.

## 문제가 생겼을 때

- **지원하지 않는 빌드 / 해시 불일치:** 지원 버전과 실제 `Content` 경로를 확인합니다. 다른 버전 패치나 업데이트 전 백업을 덮어쓰지 마세요. Xbox 앱에서 원본을 검사·복구한 뒤 다시 검사합니다.
- **게임 실행 중:** ‘플레이’ 버튼이 있는 런처도 종료합니다.
- **이전 자막·음성이 남음:** 게임·런처를 닫고 같은 설치기에서 다시 검사합니다. 캐시나 저장 데이터를 직접 지우지 마세요.
- **화면비·HUD 이상:** 와이드 설치 여부와 런처의 명시적인 **16:9 해상도**를 확인하고 게임을 재실행합니다.
- **4K 성능 문제:** 1080p와 낮은 MSAA로 확인합니다.
- 해결되지 않으면 [Issues](https://github.com/schultz1138/crimson-skies-korean-wide/issues)에 **게임 빌드, 설치기 버전, 옵션, 해상도·MSAA, 발생 구간과 오류 메시지**를 알려주세요. 로그의 개인 경로·계정명은 가려도 됩니다.

[2611 검증 기록](https://github.com/schultz1138/crimson-skies-korean-wide/blob/main/unified/verification-2611-beta1.json)에서 실제 플레이 범위를 확인할 수 있습니다. 전 캠페인과 모든 더빙 대사의 최종 청취 검수는 완료하지 않은 베타입니다.

## 개발자용 소스 빌드

소유한 2611 원본 Content, 2608 원본 Native DLL, 압축 해제한 공개 0.14.0 Beta 2, CPython과 `pefile==2024.8.26`, `capstone==5.0.9`, `keystone-engine==0.9.2`가 필요합니다. 새 출력 폴더를 사용하세요.

```powershell
python unified/build_2611.py --stock "D:\2611\Content" --previous-native "D:\2608\Content\xefu_2ae70168_ceb51ba7_9b9c95a0_541622e1_d1689465.dll" --beta "D:\Beta2" --out "D:\CS2611-output"
```
