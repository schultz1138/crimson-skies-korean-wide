# Crimson Skies 선택형 통합 설치기

소유한 Windows x64 게임 **2608.3123.1.0**에 필요한 기능을 한 번에
설치하는 오프라인 시험본입니다. 원본 게임 파일은 포함하지 않습니다.
더빙 음성은 제작 완료된 차분 데이터로 적용합니다. API 키가 필요 없습니다.

[GitHub 다운로드](https://github.com/schultz1138/crimson-skies-korean-wide/releases/tag/v0.14.0-beta.1) · [English](README.en.md)
실행용 ZIP은 `CrimsonSkies-Unified-0.14.0-beta.1.zip`이며 소스 ZIP은 별도입니다.

## 개발 중: Beta 2 설치 메타데이터 호환성 수정

현재 공개 다운로드는 Beta 1입니다. 이 소스의 다음 빌드 대상은 **0.14.0-beta.2 후보**이며,
공식 Xbox 확인·복구 뒤 같은 게임 빌드의 `appxmanifest.xml`이 달라져 Beta 1의 상태 검사가
중단되는 문제를 수정합니다. 확인한 배포 상태와 복구 직후 상태의 **두 전체 해시·크기만**
호환 형태로 허용하고, 게임 이름·버전·아키텍처·Publisher 및 나머지 파일 검증은 유지합니다.
XML이 다른 형태로 수정됐거나 게임 빌드가 다르면 계속 중단합니다. 게임 메타데이터를
덮어쓰거나 검사를 건너뛸 필요는 없습니다. 이 수정은 SAC 호환성을 바꾸지 않습니다.

Beta 1에서 메타데이터 검사 오류가 나오면 설치를 중단하고 수정 버전 안내를 확인하세요.
기존 공개 ZIP은 교체하지 않으며, 다음 버전은 독립된 백업·복구 기록을 사용합니다.
Beta 1이 설치돼 있다면 **Beta 1의 설치 전 복구부터** 실행하세요.

개발 검증: `python unified/tests/host_metadata.py --package PACKAGE --out NEW_OUTPUT`.
`--owned-manifest PATH`를 반복 지정하면 본인이 보유한 두 원본 XML도 읽기 전용으로 검증합니다.
테스트와 배포물에는 게임의 XML 원문을 포함하지 않습니다.
실제 설치·첫 임무·원본 복구 결과와 검증 범위는 [Beta 2 후보 검증 기록](verification-beta2.json)에 정리했습니다.

## Code signing policy

Beta 1의 설치기와 동봉 xdelta는 미서명 상태입니다. 이전 설치기는 Smart App Control이
켜진 PC에서 실행 차단을 재현했습니다. 일반 팬 패치는 미서명 ZIP으로
배포할 수 있으며 SignPath 신청은 선택 사항입니다. [배포와 선택적 서명](SIGNING.md)을
확인하세요. 체크섬 검증은 Windows의 실행 허용을 의미하지 않습니다.

> [!WARNING]
> **SAC는 설치와 패치된 게임 실행 모두에 영향을 줍니다.** 현재 공개 Beta 1 설치기와 동봉 xdelta는 미서명입니다.
> **SAC 켬 상태에서 와이드스크린·추가 자막용 수정 DLL의 차단을 확인했습니다. 설치 후 SAC를 다시 켜면 패치된 게임도 차단될 수 있습니다.** 설치할 때만 잠깐 끄는 것으로 플레이 호환성이 확보되지는 않습니다.
> 최근 Windows 11 업데이트에서는 재설치 없이 SAC를 다시 켤 수 있습니다. 다만 기기·업데이트·설정에 따라 재활성화 조건이 다르므로 해당 PC의 Windows 보안 안내를 확인하세요.
> SAC를 끄면 PC 전체의 앱 실행 보호가 줄어듭니다. SAC에는 개별 앱만 허용하는 예외가 없으며, 보안 설정 변경 여부는 사용자가 판단해야 합니다. SAC를 유지하려면 수정 DLL을 사용하는 구성의 설치를 보류하세요.
> 설치기는 보안 설정을 자동으로 변경하지 않습니다. 설치기만 서명해도 수정 게임 DLL의 차단까지 해결되는 것은 아닙니다. 무료 서명 신청은 초안에서 보류했으며 제출·승인되지 않았습니다.
>
> [Microsoft SAC 안내](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions) · [서명 준비 현황](SIGNING.md)

## Smart App Control (SAC)

2026-11-09 시험에서 설치기 실행과 게임 실행을 따로 확인했습니다.

| 구성 | 이 PC에서 확인한 결과 |
| --- | --- |
| 공개 Beta 1의 와이드스크린·추가 자막용 수정 DLL | 실제 게임 실행에서 수정 GPU DLL이 SAC에 차단됨. 와이드·자막 Native DLL도 별도 로드 진단에서 차단됨 |
| 별도 BAT 실험 후보: 한국어 더빙·4:3·원본 Native/GPU DLL 유지 | SAC 켬 상태에서 웹 다운로드본 설치·첫 임무 플레이·원복·재설치 성공 |
| 원본 게임 | Xbox 공식 확인·복구 후 SAC 켬 상태에서 실행 성공 |

**BAT 후보는 미공개 실험본이며, 공개 Beta 1의 ‘한국어 더빙만’ 프리셋과 동일하지 않습니다.**
이 결과를 공개 Beta 1 전체 또는 모든 PC의 SAC 호환으로 해석하지 마세요.
기본 영상 자막과 필요한 한글 메뉴 자산은 원본 DLL 유지 후보에도 남아 있습니다.

SAC를 다시 켤 수 있는 환경에서도 수정 DLL의 실행 허용은 별도 문제입니다.
따라서 ‘설치 후 SAC를 다시 켜면 전체 패치를 계속 플레이할 수 있다’고 안내하지 않습니다.
공식 파일 검토와 최종 DLL의 신뢰·서명 경로를 조사했지만, 전체 구성의 SAC 호환 해법은 아직 확보하지 못했습니다.

## 설치

1. 게임과 `플레이` 창을 종료하고 ZIP 전체를 새 폴더에 풉니다.
2. `CrimsonSkiesSetup.exe`를 실행하고 게임 폴더 또는 `Content`를 선택합니다.
3. 필요한 항목을 고른 뒤 **상태 검사 → 선택 항목 설치**를 누릅니다.
4. 완료 후 **플레이 창 열기**로 기존 실행기를 열어 플레이합니다.

별도의 0.11 설치 과정을 거치지 않고 정확한 원본에서 시작할 수 있습니다.
기존 0.11 기반 패치도 지원합니다. 기존 Alpha2 더빙/자막이나 0.12 언어팩은
이전 도구로 먼저 복구하세요. Alpha2는 **자막 복구 → 음성 복구** 순서입니다.
이전 도구의 백업 기록을 통합 설치기의 복구 기록으로 가져오지는 않습니다.
이전 **0.14 통합 설치기**를 사용했다면 해당 버전의 **설치 전 복구**를 먼저 실행한 뒤
Beta 1로 설치하세요. 버전별 백업과 복구 기록은 서로 인계하지 않습니다.

## Beta 1의 프리셋

음성·자막 프리셋 중 하나를 고르고, 와이드스크린은 별도로 선택합니다.

| 프리셋 | 동작 |
| --- | --- |
| 원본 음성·자막 | 영어 음성과 게임 기본 자막 |
| 영어 음성 + 한국어 자막 | 영어 음성을 유지하고 한국어 번역 자막·메뉴·글꼴 적용 |
| 한국어 더빙만 | 한국어 음성 적용, 추가 무전·게임 내 컷신 자막 끔 |
| 한국어 더빙 + 맞춤 자막 | 한국어 음성과 실제 더빙 대사에 맞춘 자막 적용 |

더빙 프리셋은 필요한 한글 메뉴·글꼴을 함께 적용합니다. ‘더빙만’에서도 **기본 영상 자막은 유지**합니다.
‘더빙만’은 모든 글자·영상 자막을 지우거나 원본 메뉴를 그대로 보존하는 모드가 아닙니다.
더빙에 기존 번역 자막을 조합하는 선택은 새 화면에서 제공하지 않습니다.

와이드스크린·고해상도 체크는 4:3/16:9 전환, 최대 4K, HUD 보정, 4K AA 유지를
별도로 적용합니다. 프리셋을 바꿔도 이 체크는 유지됩니다. 와이드만 필요하면
원본 음성·자막 + 와이드를 선택하고, 완전 원본은 원본 음성·자막 + 와이드 해제입니다.
설치 이후에도 같은 도구에서 프리셋을 전환할 수 있습니다.

## 백업과 복구

전체 더빙은 약 **14GB**의 추가 여유 공간을 권장합니다. 필요한 공간을
설치 전에 확인하고, 바뀌는 파일만 백업·준비합니다. 파일 전체 SHA-256을
확인하고 모든 결과를 준비한 뒤 교체합니다. 알려진 게임 자산 캐시도 선택한
구성과 일치하도록 갱신합니다. 체크포인트와 그 밖의 캐시 바이트는 그대로 보존하며,
알 수 없는 캐시 내용이나 부족한 기존 할당 공간은 덮어쓰지 않고 거부합니다.
이전 구성의 무전 자막이 캐시에 남는 현상과 ‘더빙만’에서 추가 자막이 나타나는 현상을 수정했습니다.

**설치 전 복구**는 이 설치기 첫 실행 직전의 원본 또는 0.11 상태로 돌아갑니다.
중단 기록이 있으면 **중단 작업 복구**를 먼저 실행하세요. 알 수 없는 변경은
덮어쓰지 않습니다. 백업은 아래 위치에 보관되므로 지우지 마세요.

`%LOCALAPPDATA%\CrimsonSkiesUnified\Backups`

설정에서는 언어·해상도 선택만 다룹니다. AA 등 다른 설정과 저장 프로필은
변경하지 않습니다. 설치 중에는 다른 설치기나 게임을 실행하지 마세요.
이 도구가 소유한 설치 상태를 이전 개별 설치기로 변경하면 상태가 달라져
복구가 거부될 수 있으므로 구성 변경은 이 통합 도구에서 진행하세요.

## 소스 빌드

기존 `pipeline/build.py --game-only`로 원본에서 0.11을 재현하고,
`dubbing/build_audio.py`, `dubbing/build_captions.py`로 더빙/자막 대상 파일을
준비합니다. 음성 생성 자체는 이 패키저의 역할이 아닙니다.

```powershell
python unified/build.py --stock D:\owned-stock\Content --foundation D:\source-011\generated-content --full-dub D:\full-dub\Content --dub-captions D:\caption-build\Content --native-work D:\source-011\native-work --xdelta D:\deps\xdelta3.exe --out D:\unified-014-build
```

`stock`, `foundation`, `full-dub`에는 26개 원본 볼륨과 런처/패키지 식별 파일도
준비해야 합니다. 파이프라인이 생성한 변경 파일만 별도 출력에 있다면, 소유한
원본의 **별도 복사본**에 그 결과를 덮어 각 입력 트리를 만드세요. 실제 게임
설치 폴더를 출력으로 사용하지 마세요. `dub-captions`에는 세 변경 파일만 있어도
됩니다. 새로운 출력 폴더를 사용하세요. 배포 ZIP에는 차분·도구·안내만 들어갑니다.

현재 소스 빌드는 Beta 1 폴더와 `preparation.json`, `release` 폴더의 일반 미서명
ZIP·SHA-256·검증 보고서를 생성합니다. `--prepare-only`는 ZIP 없이 준비만 합니다.
이미 준비된 폴더는 `release.py finalize`로 패키징할 수 있습니다. 서명이 필요한
별도 경로에서만 `--require-signatures`를 사용합니다. [자세한 안내](SIGNING.md).

선택형 Native는 공개 캡션 컴파일러가 선언한 후크와 디스패치 범위만 원본
명령으로 복구합니다. 와이드스크린을 끄면 공개 0.10 캡션 단계의 Native와
원본 GPU/해상도 메뉴를 사용합니다. 기본 전체 선택의 Native/게임 볼륨은
기존 Alpha2와 같습니다. 실제 설치·플레이 검증 범위는 배포의 검증 기록에 명시합니다.
엔딩까지의 전 구간 플레이와 4K 플레이 검증은 완료하지 않았습니다.

설치 소스 MIT, 글꼴 SIL OFL. 원작 및 AI 음성 고지는 포함한 라이선스를 확인하세요.

## 설치기 검사

`tests/transactions.py`는 게임 데이터 대신 작은 합성 파일을 사용하되 실제
구성 그래프와 설치 엔진을 검사합니다. 모든 선택 조합, 오류 시 롤백,
프로세스 강제 종료 후 복구, 백업·차분·원본 변조 거부, 설정 보존을 포함합니다.
`UNIFIED_TEST`로 컴파일하는 테스트 실행기는 배포하지 않습니다.

```powershell
python unified/tests/transactions.py --package D:\unified-014-build\CrimsonSkies-Unified-0.14.0-beta.1 --out D:\unified-synthetic-001
python unified/tests/owned_roundtrip.py --package D:\unified-014-build\CrimsonSkies-Unified-0.14.0-beta.1 --stock D:\owned-stock\Content --out D:\unified-owned-test-001
```

두 검사 모두 새 출력 폴더를 요구합니다. 실제 크기 검사는 원본 입력을 별도로
복사하고 테스트 전용 백업·설정 경로를 사용합니다. 설치된 게임을 변경하지 않습니다.
게임 플레이 검사를 대신하는 검사는 아닙니다. 프로필 관리는 기존 별도 런처의
기능이며, 이 시험본 설치 화면에는 포함하지 않습니다.
