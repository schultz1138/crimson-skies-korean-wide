`CrimsonSkies-Unified-0.14.0-beta.2.zip`의 **CrimsonSkiesSetup.exe**를 위한 안내입니다.
대상은 **Crimson Skies: High Road to Revenge**, Windows x64 게임 빌드 **2608.3123.1.0**입니다. 게임은 별도로 설치해야 합니다.

## 시작 전 준비

- 원본 게임을 한 번 실행해 정상 작동과 필요한 컨트롤러 연결을 확인합니다.
- 진행 상황을 저장하고 **게임과 ‘플레이’ 버튼이 있는 런처 창을 모두 종료**합니다.
- 전체 더빙은 약 **14GB의 추가 여유 공간**을 권장합니다. 게임 드라이브와 Windows 사용자 폴더가 있는 드라이브의 공간을 모두 확인하세요.
- 이전 패치를 썼다면 아래의 기존 사용자 표를 먼저 확인하세요.

> **실행 차단 안내:** 배포본은 미서명이며 Smart App Control(SAC)이 설치기 또는 패치된 게임을 차단할 수 있습니다. SAC를 끄면 PC 전체의 앱 실행 보호가 줄어듭니다. 다시 켤 수 있는지는 PC·Windows 상태에 따라 다르고, 다시 켜도 게임이 차단될 수 있습니다. 설치기는 보안 설정을 바꾸지 않습니다. SAC를 유지하려면 설치를 보류하세요. [자세한 안내](#smart-app-control-sac)

## 처음 설치하기

### 1. 설치용 ZIP 받기

[Beta 2 릴리스](https://github.com/schultz1138/crimson-skies-korean-wide/releases/tag/v0.14.0-beta.2) 아래쪽 **Assets**를 펼쳐 **`CrimsonSkies-Unified-0.14.0-beta.2.zip`**을 받습니다.
`Source code (zip)`·`Source code (tar.gz)`는 개발용 소스입니다. `SHA256SUMS.txt`는 다운로드 파일의 무결성을 확인하려는 사용자를 위한 체크섬 목록입니다.

### 2. 전체 압축 풀기

ZIP을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택하고 새 폴더에 풉니다. 압축이 풀린 폴더에서 `CrimsonSkiesSetup.exe`를 실행하세요.
설치기와 `manifest.json`, `patches`, `tools` 폴더는 함께 있어야 합니다. ZIP 전체를 풀면 필요한 파일이 같이 준비됩니다.

원본에서 시작할 때 별도의 0.11 설치, Python 설치, API 키, 음성 재생성은 필요 없습니다.

### 3. 실제 게임 폴더 선택

**폴더 선택 / Browse**를 누르고 **실제 게임 설치 폴더 또는 그 안의 Content**를 선택합니다. 예시는 다음과 같습니다. 드라이브·폴더명은 PC마다 다를 수 있습니다.

```text
C:\XboxGames\Crimson Skies- High Road to Revenge\Content
```

설치 위치를 모르겠다면 Xbox 앱의 해당 게임 관리 화면에서 설치 위치를 확인하세요.

### 4. 음성·자막과 와이드 선택

[옵션 표](#어떤-옵션을-고르나요)에서 원하는 구성을 고릅니다.
처음 열면 **한국어 더빙 + 맞춤 자막**, **와이드스크린·고해상도 켬**이 선택돼 있습니다. 원하는 구성에 맞게 두 항목을 확인하세요.

### 5. 상태 검사 후 설치

**상태 검사 / Check**를 누릅니다. 아래 기록 창에 **`지원 상태 / Supported state:`**가 나오면 **선택 항목 설치 / Install selected**를 누릅니다. 상태 검사는 파일을 설치하지 않습니다.

오류·중단 메시지가 나오면 [문제 해결](#문제가-생겼을-때)을 확인하세요. 설치 중에는 게임이나 다른 설치기를 열지 말고 다음 메시지를 기다립니다.

> **선택한 구성요소 설치와 전체 검증을 마쳤습니다.**

바뀌는 파일은 자동으로 백업합니다. 저장 프로필은 변경하지 않습니다.

### 6. 실행과 적용 확인

**플레이 창 열기 / Open game**를 눌러 게임 런처를 엽니다.
와이드를 적용했다면 **설정 → 그래픽 → 해상도**에서 **1920×1080 (16:9)** 등 원하는 16:9 해상도를 선택하고 **플레이**합니다. 해상도 변경은 다음 게임 실행에 적용됩니다.

게임에서 선택한 자막·음성과 화면비를 확인하세요. 한국어 구성의 메뉴가 영어라면 런처의 언어 설정도 확인합니다. 컨트롤러 연결을 요구하면 원본 게임에서 사용하던 컨트롤러를 연결하세요.

## 어떤 옵션을 고르나요?

음성·자막 프리셋 **하나**와 와이드 체크를 **따로** 선택합니다.

| 원하는 플레이 | 음성·자막 프리셋 | 와이드 체크 |
| --- | --- | --- |
| 영어 음성 + 한국어 자막 | **영어 음성 + 한국어 자막** | 원하는 대로 |
| 한국어 음성만 듣기 | **한국어 더빙만 (추가 자막 끔)** | 원하는 대로 |
| 한국어 음성 + 대사에 맞는 자막 | **한국어 더빙 + 맞춤 자막** | 원하는 대로 |
| 영어 원본에 와이드만 적용 | **원본 음성·자막** | **켬** |
| 원본 음성·자막과 4:3 화면 | **원본 음성·자막** | **끔** |

- **더빙만:** 추가 무전·게임 내 컷신 자막을 끕니다. **기본 영상 자막과 필요한 한글 메뉴·글꼴은 유지**합니다.
- **와이드:** 4:3/16:9 해상도 선택, HUD 보정과 고해상도 옵션을 적용합니다. 최대 4K는 내부 렌더링 해상도이며 실제 출력은 창·모니터 크기를 따릅니다.
- 프리셋을 바꿔도 와이드 체크는 유지됩니다. 설치 전에 두 선택을 확인하세요.
- 더빙은 미리 제작된 **AI 생성 음성**입니다. 설치할 때 계정·API 키나 음성 생성을 요구하지 않습니다.

## 옵션 변경과 복구

### 설치 후 다른 구성으로 바꾸기

게임과 플레이 창 종료 → **같은 Beta 2 설치기** 실행 → 같은 게임 폴더 선택 → 프리셋·와이드 선택 → **상태 검사 → 선택 항목 설치**를 사용합니다.

### 설치하기 전으로 돌아가기

게임과 플레이 창 종료 → **Beta 2 설치기**에서 같은 게임 폴더 선택 → **설치 전 복구 / Restore**를 누릅니다.
**`설치 전 상태로 복구했습니다.`** 메시지가 나오면 완료입니다.

복구 대상은 **Beta 2로 처음 설치하기 직전 상태**입니다. 원본에서 설치했다면 원본, 0.11 기반에서 설치했다면 그 0.11 상태로 돌아갑니다. 옵션 변경 직전으로 되돌리는 버튼은 아닙니다.

### 설치·복구가 중간에 끊겼다면

중단된 작업이 있다는 안내가 나오면 **중단 작업 복구 / Recover**를 먼저 누릅니다. 이 버튼은 끊긴 작업을 정리해 작업 시작 전 상태로 돌립니다. 완료 뒤 다시 설치하거나 설치 전 복구를 선택하세요.

백업은 같은 Windows 사용자 계정의 다음 위치에 있습니다. 탐색기 주소창에 붙여 넣어 열 수 있습니다.

```text
%LOCALAPPDATA%\CrimsonSkiesUnified\Backups
```

이전 설치기와 백업은 보관하세요. 이 설치기로 만든 백업이 없거나 다른 도구가 게임 파일을 바꾸면 복구가 거부될 수 있습니다.

## Smart App Control (SAC)

시작 메뉴에서 **Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤**을 열면 현재 상태와 변경 안내를 확인할 수 있습니다.

설치기와 동봉 도구는 미서명입니다. 수정 게임 DLL은 SAC 켬에서 차단된 기록이 있으며, **Beta 2의 설치 검사 수정은 SAC 차단 해결과 별개**입니다.

Microsoft는 최근 업데이트에서 재설치 없이 다시 켤 수 있는 환경을 안내하지만, 해당 PC에서 가능한지는 기기·업데이트·설정에 따라 다릅니다. **반드시 다시 켤 수 있다고 가정하지 말고 Windows 보안의 안내를 확인하세요.** 다시 켜도 패치된 게임은 재차단될 수 있습니다. [Microsoft 공식 FAQ](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

SAC에는 특정 앱 하나만 허용하는 예외가 없습니다. 끄면 PC 전체의 앱 실행 보호가 줄어듭니다. 보호 기능을 유지하려면 설치를 보류하세요. 설치기는 Windows 보안 설정을 자동으로 바꾸지 않습니다.

별도 원본 DLL·BAT 실험은 현재 배포 ZIP과 다른 구성입니다. 그 결과를 Beta 2 전체의 SAC 호환으로 해석하지 마세요. [배포·서명·실험 기록](SIGNING.md)

## Beta 2 변경과 검증 범위

Xbox 앱의 공식 **검사 및 복구** 뒤 같은 빌드의 설치 메타데이터가 달라져 Beta 1이 거부하던 문제를 수정했습니다. 지원하는 두 원본 형태만 허용하며 다른 빌드·알 수 없는 변경은 계속 거부합니다.

Beta 1의 8조합과 동일한 차분을 사용하며 Beta 2 전체 프리셋의 실제 설치 → 1080p 첫 임무 플레이 → 원본 복구를 다시 확인했습니다. 전 캠페인·4K 플레이와 모든 대사의 최종 청취 검수는 남아 있습니다. [Beta 2 검증 기록](https://github.com/schultz1138/crimson-skies-korean-wide/blob/main/unified/verification-beta2.json)

## 개발자용: 소스 빌드

기존 `pipeline/build.py --game-only`로 원본에서 0.11을 재현하고,
`dubbing/build_audio.py`, `dubbing/build_captions.py`로 더빙/자막 대상 파일을
준비합니다. 음성 생성 자체는 이 패키저의 역할이 아닙니다.

```powershell
python unified/build.py --stock D:\owned-stock\Content --foundation D:\source-011\generated-content --full-dub D:\full-dub\Content --dub-captions D:\caption-build\Content --native-work D:\source-011\native-work --xdelta D:\deps\xdelta3.exe --out D:\unified-014-build
```

`stock`, `foundation`, `full-dub`에는 26개 원본 볼륨과 런처/패키지 식별 파일도
준비해야 합니다. 파이프라인이 생성한 변경 파일만 별도 출력에 있다면, 소유한
원본의 **별도 복사본**에 그 결과를 덮어 각 입력 트리를 만드세요. 실제 게임
설치 폴더를 출력으로 사용하지 마세요. `dub-captions`에는 세 변경 파일만 있어도
됩니다. 새로운 출력 폴더를 사용하세요. 배포 ZIP에는 차분·도구·안내만 들어갑니다.

현재 소스 빌드는 Beta 2 폴더와 `preparation.json`, `release` 폴더의 일반 미서명
ZIP·SHA-256·검증 보고서를 생성합니다. `--prepare-only`는 ZIP 없이 준비만 합니다.
이미 준비된 폴더는 `release.py finalize`로 패키징할 수 있습니다. 서명이 필요한
별도 경로에서만 `--require-signatures`를 사용합니다. [자세한 안내](SIGNING.md).

선택형 Native는 공개 캡션 컴파일러가 선언한 후크와 디스패치 범위만 원본
명령으로 복구합니다. 와이드스크린을 끄면 공개 0.10 캡션 단계의 Native와
원본 GPU/해상도 메뉴를 사용합니다. 기본 전체 선택의 Native/게임 볼륨은
기존 Alpha2와 같습니다. 실제 설치·플레이 검증 범위는 배포의 검증 기록에 명시합니다.
엔딩까지의 전 구간 플레이와 4K 플레이 검증은 완료하지 않았습니다.

설치 소스 MIT, 글꼴 SIL OFL. 원작 및 AI 음성 고지는 포함한 라이선스를 확인하세요.

## 설치기 검사

`tests/transactions.py`는 게임 데이터 대신 작은 합성 파일을 사용하되 실제
구성 그래프와 설치 엔진을 검사합니다. 모든 선택 조합, 오류 시 롤백,
프로세스 강제 종료 후 복구, 백업·차분·원본 변조 거부, 설정 보존을 포함합니다.
`UNIFIED_TEST`로 컴파일하는 테스트 실행기는 배포하지 않습니다.

```powershell
python unified/tests/transactions.py --package D:\unified-014-build\CrimsonSkies-Unified-0.14.0-beta.2 --out D:\unified-synthetic-001
python unified/tests/owned_roundtrip.py --package D:\unified-014-build\CrimsonSkies-Unified-0.14.0-beta.2 --stock D:\owned-stock\Content --out D:\unified-owned-test-001
```

두 검사 모두 새 출력 폴더를 요구합니다. 실제 크기 검사는 원본 입력을 별도로
복사하고 테스트 전용 백업·설정 경로를 사용합니다. 설치된 게임을 변경하지 않습니다.
게임 플레이 검사를 대신하는 검사는 아닙니다. 프로필 관리는 기존 별도 런처의
기능이며, 이 시험본 설치 화면에는 포함하지 않습니다.
