Crimson Skies BAT 시험본 — 설치된 게임을 변경하지 않는 복사본 실험

Sandbox-Test.cmd를 실행하면 음성·자막 프리셋 4개와 와이드 켜기/끄기를 고를 수 있습니다.
번호 메뉴 또는 --list / --check / --apply 1..8 / --restore를 제공합니다.
실행 시 Python, PowerShell, 기존 CrimsonSkiesSetup.exe를 호출하지 않습니다.
Windows 기본 cmd/choice/certutil/findstr와 동봉 xdelta3.exe만 사용합니다.
Python은 유지관리자가 이 시험본을 생성하는 데만 사용합니다.

중요한 범위
- 변경 대상은 이 폴더 아래의 Sandbox\Content 복사본으로 고정됩니다.
- 실제 Xbox 설치 경로를 입력받거나 설치된 게임을 변경하는 기능은 없습니다.
- 파일 전체 SHA-256, 선택 차분, 결과 파일, 백업을 확인하고 모든 결과를 준비한 뒤 교체합니다.
- 다른 구성으로 바꾸려면 먼저 --restore로 이 복사본을 원복하세요.
- 원본 백업은 이 폴더의 State\original에 보존합니다. 정식 설치기의 백업을 공유하지 않습니다.
- 실제 게임 설정·실행 캐시·저장 프로필은 읽거나 변경하지 않습니다.
- 따라서 정식 설치기 대체품이 아닙니다. 실행 캐시 갱신과 설정 전환은 별도 구현·검증이 필요합니다.

작은 호환성 검사본(ARTIFICIAL_COMPATIBILITY_PROBE)
Sandbox\Content에는 인위적으로 만든 작은 시험 파일만 있습니다. 게임 원본은 포함하지 않습니다.
여기서도 xdelta가 실제 차분을 적용하고, 8구성의 결과와 원복을 해시로 검사합니다.
버전 조회만 성공한 경우와 실제 패치 작업까지 성공한 경우를 구분하기 위한 검사입니다.

실제 크기 복사본(OWNED_GAME_SANDBOX)
자신이 소유한 정확한 원본 게임 파일의 별도 복사본이 필요합니다.
복사본·백업·준비 공간을 위해 약 14GB 이상의 여유 공간을 권장합니다.
알 수 없는 파일 또는 변경된 백업·차분은 거부합니다.

SAC 검증
BAT 자체와 동봉 도구도 Windows 보안 검사를 받을 수 있습니다.
BAT 방식이면 반드시 SAC를 통과한다는 뜻이 아닙니다.
검사 기록에는 실행 전후의 실제 SAC 상태를 읽어서 남깁니다.
SAC를 끈 PC에서의 성공은 SAC 호환성 증거가 아닙니다.
SAC가 켜진 다른 환경에서 다운로드·압축 해제한 검사본을 그대로 실행해 결과를 확인해야 합니다.
이 시험본은 보안 설정, 실행 정책, 인증서 저장소 또는 다운로드 출처 표식을 변경하지 않습니다.
한글 메뉴는 별도 텍스트로 표시하고, 실행 CMD 명령문은 ASCII만 사용합니다.
검사본이 허용되어도 수정된 게임 DLL의 실행과 다른 PC의 허용 여부는 별도 확인 대상입니다.

시험본의 제한
경로에 %, !, &, ^, 괄호, |, <, >가 있으면 실행을 거부합니다. 일반 로컬 폴더와 공백은 지원합니다.
동시 실행은 State\.lock으로 거부합니다. 강제 종료 뒤에는 파일을 지우거나 게임에 수동 적용하지 마세요.
중단된 콘솔이 모두 닫혔는지 확인하고 시험 폴더를 보존한 상태로 진단해야 합니다.
전원 차단 복구, 모든 경로 형식 및 정식 설치 환경의 내구성은 아직 인증하지 않았습니다.
현재 공개 Beta 1 ZIP과 릴리스는 이 실험으로 변경되지 않습니다.
