검증 대상
Windows x64 패키지 빌드 2608.3123.1.0 전용입니다.
원본 5개 파일 조합과 공개 한글 베타 0.10.0-beta.1 조합을 지원합니다.
게임 버전 정보와 5개 파일의 SHA-256을 함께 검사합니다.

차분과 배포 파일
• 정방향 VCDIFF 차분 6개, 합계 340,969바이트
• 원본→통합본 5개 및 이전 한글 베타 Native→통합본 1개를 모두 복원해
  최종 파일 5개의 기대 크기·SHA-256과 정확히 일치하는 것을 확인했습니다.
• 기존 한글 베타의 Data0000·Data0005는 이미 최종 파일과 같으므로 유지합니다.
• 차분의 원본 경로 메타데이터를 제거했습니다. 게임 원본·전체 DLL·게임 데이터,
  개인 설정·저장 파일·디버그 도구는 배포하지 않습니다.
• 글꼴·xdelta3·정적 의존 도구의 라이선스와 고지 파일을 포함했습니다.

최종 설치기 검증
최종 소스 기준 독립 검증 191개를 통과했습니다. 이 수치는 단순 요약 행이나
같은 상태를 만드는 중복 비트 마스크를 별도 시험으로 세지 않은 결과입니다.
• 원본 및 이전 한글 베타의 설치·복구, 재설치와 백업 불변성
• 부분 적용 상태의 재개·복구 80개 조합
  (원본의 서로 다른 상태 32개 + 이전 베타의 상태 8개, 각각 재개·복구)
• 해상도 선택 키 23종과 AA·음량 등 다른 설정 바이트 보존
• 설치 후 파일은 같지만 복구 기록이 없는 경우와, 소유한 중단 기록이 있는
  경우를 구분하며, 존재하지 않는 원본 백업을 만들어 내지 않는 동작
• 손상되거나 다른 출처의 파일·차분·도구·백업·기록 거부
• 버전 정보 XML, 잘못된 경로·정션, 동시 실행·파일 잠금 검사
• 중간 실패 시 파일·설정 복구, 다른 프로그램이 바꾼 현재 설정 보존
• 설정 변환 전·후 64KiB 크기 제한 및 경계값

실제 크기의 파일을 사용한 원본·이전 베타 설치→복구 2회도 통과했습니다.
각각 최종 파일 5개와 복구 파일 5개를 SHA-256으로 확인했고, 백업과 AA·그 밖의
설정 보존을 확인했습니다. 이 시험은 최종 설치기 소스에서 테스트용 경로만
분리한 도구로 수행하여 실제 설치 게임과 사용자 설정을 변경하지 않았습니다.
배포 EXE는 현재 게임에 읽기 전용 상태 검사를 수행해 성공했고 GUI도 확인했습니다.

게임 실행과 사용자 확인
• 튜토리얼 무전과 줄바꿈, 씨헤이븐 보스 등장·로봇 변신 컷신, 이후 임무의
  무전·컷신 한글 자막이 정상이라는 사용자 확인을 받았습니다.
• 대화는 하단, 목표는 중앙에 분리되며 별도 자막 프로그램이 필요하지 않습니다.
• Noto Sans CJK KR Bold에서 변환한 CS Korean Sans를 포함했습니다.
• 1080p에서 레이더 지도·로켓 숫자·적 체력바·정지 메뉴 목표 상자 보정을
  사용자에게 확인받았습니다.
• 최종 Native·GPU 파일은 사용자가 정상이라고 확인한 통합 시험본과 같습니다.
• 4K+AA의 버퍼 부족 원인을 재현하고, 해당 조건의 보조 버퍼 풀 한도를
  조정한 뒤 실제 실행에서 새 한도와 AA 유지, 기존 한도를 넘는 사용을 확인했습니다.
• 최종 4K·4x MSAA 플레이는 정상이라는 사용자 확인을 받았습니다.

남은 검증 범위
본편 무전·게임 내 컷신, 기존 영상·크레딧의 한글 데이터를 통합했지만
엔딩까지 모든 장면의 실제 플레이 확인이 끝난 것은 아닙니다.
짧은 외국어 외침 4개의 정확한 원문 확인이 남아 있습니다.
마지막 4K 시험의 정확한 임무와 기간은 기록되지 않았습니다.
4K는 내부 렌더링 해상도이며, 실제 관찰한 모니터·최종 출력은 1080p입니다.
물리적인 4K 모니터 출력이나 다양한 PC의 장시간 플레이 검증은 별도입니다.
이 범위를 구분하기 위해 베타로 배포합니다.

제보할 때는 임무·장면, 해당 대사, 재현 순서, 해상도와 AA 설정을 적어 주세요.
