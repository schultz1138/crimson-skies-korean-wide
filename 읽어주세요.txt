Crimson Skies 한국어·와이드스크린 통합 패치
0.11.0 베타 1 · 2026-11-07

지원 환경
Windows x64 패키지 빌드 2608.3123.1.0 전용입니다. 설치기는 패키지의
버전 정보와 게임 파일 5개의 SHA-256을 검사합니다. 게임은 별도로 필요합니다.
이 배포본에는 게임 원본 파일을 넣지 않고 VCDIFF 차분만 담았습니다.

설치 가능한 상태
• 지원 빌드의 수정하지 않은 원본
• 이전 공개 한글 패치 0.10.0-beta.1이 적용된 상태
• 이미 통합본과 같은 파일이면 검사 결과에 표시하며 중복 설치하지 않습니다.
다른 모드나 중간 시험본이 섞인 상태는 파일을 변경하기 전에 중단합니다.

설치
1. 진행 상황을 저장하고 게임과 '플레이' 버튼이 있는 실행기를 모두 종료합니다.
2. ZIP 전체를 일반 폴더에 풉니다. 설치 EXE만 따로 옮기지 마세요.
3. KoreanWidePatchInstaller.exe를 실행합니다.
4. 게임 폴더 또는 그 안의 Content 폴더를 선택하고 '상태 검사'를 누릅니다.
5. 지원하는 상태로 확인되면 '통합 패치 설치'를 누릅니다.
6. 설치 완료 후 평소 사용하던 방법으로 게임을 실행합니다.
   실행기 언어 설정에서 게임 언어를 '한국어'로 선택합니다.
   별도의 자막 프로그램이나 Windows 글꼴 설치는 필요하지 않습니다.

차분 복원용 도구는 함께 들어 있습니다. 설치·복구 작업을 위한 여유 공간은
게임 드라이브와 백업 드라이브에 합계 약 2GB 이상을 확보하는 것을 권장합니다.
두 드라이브가 같으면 해당 드라이브의 여유 공간을 확인하세요.

해상도와 AA
게임 실행기의 설정 → 그래픽 → 렌더링 해상도에서 선택합니다.
  4:3  : 640×480, 800×600, 1024×768, 1280×960, 1920×1440, 2560×1920
  16:9 : 1280×720, 1600×900, 1920×1080, 2560×1440, 3840×2160
선택한 해상도에 맞춰 화면비가 바뀌며 변경은 다음 게임 실행부터 적용됩니다.
4K에서도 선택한 AA를 유지합니다. 이전의 '4K 선택 시 AA 자동 끔'은 제거했습니다.

이 옵션은 내부 렌더링 해상도입니다. 최종 출력은 게임 창·모니터 크기를 따릅니다.
1080p 화면에서 4K를 선택하면 고해상도로 렌더링한 화면이 축소되어 표시됩니다.
4K와 높은 AA 설정은 GPU 및 메모리 부하를 늘립니다.

복구
1. 게임과 실행기를 종료합니다.
2. 같은 설치기에서 같은 게임 폴더를 선택합니다.
3. '설치 전 상태로 복구'를 누릅니다.

복구 대상은 이 버전을 설치하기 직전의 상태입니다.
• 원본에서 설치했다면 원본으로 복구합니다.
• 0.10 한글 베타에서 올렸다면 0.10 한글 베타로 복구합니다.
  한글 베타까지 지우려면 그 후에 이전 설치기와 그 백업을 사용하세요.
이전 설치기의 백업은 그대로 보관합니다. 저장 데이터는 읽거나 수정하지 않습니다.

백업은 현재 Windows 사용자 계정의 다음 위치에 만듭니다.
  %LOCALAPPDATA%\CrimsonSkiesKoreanPatch\Backups\<게임 폴더 식별값>\
  CrimsonSkies-KO-Wide-0.11.0-beta.1\<설치 전 상태 식별값>\
다른 PC·다른 게임 폴더의 백업이나 손상된 백업으로는 복구하지 않습니다.
이미 같은 패치가 있지만 이 설치기로 만든 백업이 없다면 이전 도구로 복구하세요.
새 해상도를 선택한 뒤 복구하면 해상도 값만 이전 실행기가 지원하는 값으로
맞추며, AA·음량 등 다른 현재 설정은 유지합니다.

베타 검증 범위
본편 무전·게임 내 컷신·영상·크레딧 자막 데이터를 통합했습니다.
튜토리얼, 씨헤이븐 보스 연출과 이후 임무의 자막, HUD 보정, 4K·AA 실행을
시험했습니다. 최종 4K·4x MSAA 플레이는 정상이라는 사용자 확인을 받았습니다.
정확한 최종 시험 임무와 기간은 기록되지 않았고, 엔딩까지 모든 장면의
실제 플레이 검증은 끝나지 않았습니다. 짧은 외국어 외침 4개의 원문 확인이
남아 있습니다. 자세한 항목은 '검증 결과.txt'에 정리했습니다.

문제 확인
• 지원하지 않는 상태: 설치 로그의 파일 검사 결과와 빌드 번호를 확인하세요.
• 실행 중 표시: 게임 화면과 '플레이' 버튼 창을 모두 닫고 다시 검사하세요.
• 권한·용량 오류: 선택한 폴더의 쓰기 권한과 여유 공간을 확인하세요.
• 알 수 없는 파일·다른 모드: 원래 상태로 복구한 뒤 다시 검사하세요.
제보할 때 임무/장면, 재현 순서, 해상도, AA 값, 해당 대사를 함께 적어 주세요.

licenses/, FONT-NOTICE.txt : 글꼴·도구·설치기 라이선스와 고지

글꼴은 Noto Sans CJK KR Bold에서 변환한 CS Korean Sans이며 SIL OFL 1.1을
따릅니다. 글꼴·도구 고지는 FONT-NOTICE.txt와 THIRD-PARTY-NOTICES.txt,
각 라이선스 전문은 licenses/에서 확인할 수 있습니다.
